# Evaluation reports

Generated by `aiact-qa eval --out reports/<run>`; each run contains `eval_summary.json` (aggregates overall and per
category) and `eval_results.jsonl` (per question: answer, sources, citations, metrics, latency, token usage).

* `extractive/` – baseline without an LLM (retrieval quality + extractive answers). Answer-level metrics such as
  `must_contain` are only meaningful for LLM runs (`aiact-qa eval --provider anthropic|openai|mistral ...`).
