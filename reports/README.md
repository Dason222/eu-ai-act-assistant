# Evaluation reports

Generated by `aiact-qa eval --out reports/<run>`; each run contains `eval_summary.json` (aggregates overall and per
category) and `eval_results.jsonl` (per question: answer, sources, citations, metrics, latency, token usage).

* `extractive/`: baseline without an LLM (retrieval quality and quoted provisions). Answer-level metrics such as
  `must_contain` describe the quoted text, so compare them only with other extractive runs.
* `openai-gpt-5.4-mini/`: the same 57 questions answered by OpenAI `gpt-5.4-mini`.
* `redteam/`: 15 jailbreak and injection probes × 3 runs (`scripts/run_redteam.py`); `summary.md` holds the
  automatic scores, `REVIEW.md` the manual verdicts on flagged answers.
